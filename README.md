# glacayo.com

**Blog de informática** — the personal tech log of [Geovanny Lacayo](https://github.com/glacayo): programming, web development, AI, AI agents, bots, homelabs, hardware, security and whatever comes next.

The site is designed like a 1990s dial-up BBS: categories are message bases, posts are numbered messages, and the whole frame speaks the DOS 16-colour palette on a black screen, under a pixel-art night sky.

## Features

- **Bilingual** (Spanish and English) with prefixed routes (`/es/`, `/en/`) and `hreflang` alternates.
- **Markdown/MDX posts** in the repository with typed frontmatter (Astro Content Collections). Git is the CMS.
- **Message bases** (categories), a numbered message list, and a sticky contents index on long posts.
- **Post actions:** like (global counter), share (Web Share API with copy-link fallback), save (local bookmarks) and download the post as `.md`.
- **Related posts**, previous/next navigation and a "continue where you left off" reading position.
- **Static search** with [Pagefind](https://pagefind.app/), one index per language.
- **Narrated posts:** each post gets a one-time AI narration (OpenAI Realtime, voice Ash) stored in Cloudflare R2 and played by a terminal-style player at the top of the post.
- **Keyboard first:** `/` search, `N`/`P` next/previous message, `00`–`14` jump to a base, `L`/`H`/`B`/`D` post actions, `A` play or pause the narration.
- **Pixel-art masthead** generated by code, with subtly twinkling stars (respects `prefers-reduced-motion`).

## Stack

- [Astro](https://astro.build/) (static output), TypeScript
- [Pagefind](https://pagefind.app/) for search
- [Cloudflare Pages](https://pages.cloudflare.com/) for hosting, plus one Pages Function and Workers KV for the like counter
- Fonts: [Departure Mono](https://departuremono.com/), Ubuntu and Ubuntu Mono (patched by [Nerd Fonts](https://www.nerdfonts.com/)), [JetBrains Mono](https://www.jetbrains.com/lp/mono/) — all self-hosted

## Getting started

Requires Node.js 22+ and [pnpm](https://pnpm.io/).

```bash
pnpm install
pnpm dev        # http://localhost:4321 (search works only after a build)
pnpm build      # astro build + pagefind index into dist/
pnpm preview    # serve the built site
pnpm check      # astro check (types and templates)
```

## Writing a post

Create a Markdown file under `src/content/posts/es/` or `src/content/posts/en/`:

```md
---
title: My post title
description: One or two sentences shown in lists and search results.
date: 2026-10-26
category: homelab        # see src/data/categories.ts
translationKey: my-post  # same value in both languages links the translations
# updated: 2026-11-02
# updateNote: what changed
# draft: true
---

Post content in Markdown.
```

## Deploying to Cloudflare Pages

The project is connected to Cloudflare Pages through Git: every push to `main` deploys to production and other branches get preview URLs. Build command `pnpm build`, output directory `dist`, Node.js version from `.node-version`.

The like counter uses the Workers KV namespace bound as `LIKES` in `wrangler.toml` and a `LIKES_SALT` secret set in the Pages project settings (or with `npx wrangler pages secret put LIKES_SALT --project-name glacayo-com`).

Local secrets belong in `.dev.vars`, which is git-ignored.

## Post narrations

`scripts/audio/generate.mjs` turns each post into narration text (headings, paragraphs and lists; code, tables, images and the sources list are left out), reads it with the OpenAI Realtime API (`gpt-realtime-2.1-mini`, voice `ash`), checks the transcript against the text, encodes a 64 kbps mono MP3 with ffmpeg and uploads it to Cloudflare R2. The manifest `src/data/audio.json` maps `lang/slug` to the file; the post page shows the player only when an entry exists.

A post is narrated **once**. The [Post audio](.github/workflows/post-audio.yml) workflow runs on every push to `main` that touches `src/content/posts/`, narrates posts without an entry and commits the manifest, which triggers the deploy. To regenerate a post after editing it, run the workflow manually with `posts` set to `es/<slug>,en/<slug>` (or `all`).

Repository secrets the workflow needs:

| Secret | Value |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI API key with Realtime access |
| `R2_ACCOUNT_ID` | Cloudflare account ID |
| `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY` | R2 API token with Object Read & Write on the bucket |
| `R2_BUCKET` | Bucket name, for example `glacayo-audio` |
| `AUDIO_PUBLIC_URL` | Public base URL of the bucket, for example `https://audio.glacayo.com` |

Locally, put the same variables in `.env` (git-ignored) and run:

```bash
pnpm audio --dry-run            # write the narration text to .audio-preview/, no API calls
pnpm audio --local --only es/x  # narrate one post into .audio-out/, no upload
pnpm audio                      # narrate every post without audio and update the manifest
pnpm audio --force es/x         # narrate a post again
```

## Project structure

```text
src/
  components/     UI pieces (masthead, sidebar, message table, post actions…)
  content/posts/  Markdown posts, one folder per language
  data/           categories and the generated masthead star layer
  i18n/           UI strings (es, en)
  layouts/        page shell
  pages/          routes: /<lang>/posts/<slug>/, /es/categoria/<id>/ or /en/category/<id>/, the raw .md endpoint
  scripts/        client-side enhancements
  styles/         global styles and fonts
functions/api/    Cloudflare Pages Function for the like counter
scripts/          banner.mjs (pixel-art masthead) and audio/ (post narrations)
public/           fonts, favicon, masthead image
```

The visual system is documented in [DESIGN.md](DESIGN.md) and the product context in [PRODUCT.md](PRODUCT.md).
