# glacayo.com

**Blog de informática** — the personal tech log of [Geovanny Lacayo](https://github.com/glacayo): programming, web development, AI, AI agents, bots, homelabs, hardware, security and whatever comes next.

The site is designed like a 1990s dial-up BBS: categories are message bases, posts are numbered messages, and the whole frame speaks the DOS 16-colour palette on a black screen, under a pixel-art night sky.

## Features

- **Bilingual** (Spanish and English) with prefixed routes (`/es/`, `/en/`) and `hreflang` alternates.
- **Markdown/MDX posts** in the repository with typed frontmatter (Astro Content Collections). Git is the CMS.
- **Message bases** (categories), a numbered message list, and a sticky contents index on long posts.
- **Post actions:** like (global counter), share (Web Share API with copy-link fallback), save (local bookmarks) and download the post as `.md`.
- **Related posts**, previous/next navigation and a "continue where you left off" reading position.
- **Static search** with [Pagefind](https://pagefind.app/), one index per language.
- **Keyboard first:** `/` search, `N`/`P` next/previous message, `00`–`12` jump to a base, `L`/`H`/`B`/`D` post actions.
- **Pixel-art masthead** generated by code, with subtly twinkling stars (respects `prefers-reduced-motion`).

## Stack

- [Astro](https://astro.build/) (static output), TypeScript
- [Pagefind](https://pagefind.app/) for search
- [Cloudflare Pages](https://pages.cloudflare.com/) for hosting, plus one Pages Function and Workers KV for the like counter
- Fonts: [Departure Mono](https://departuremono.com/), Ubuntu and Ubuntu Mono (patched by [Nerd Fonts](https://www.nerdfonts.com/)), [JetBrains Mono](https://www.jetbrains.com/lp/mono/) — all self-hosted

## Getting started

Requires Node.js 22+ and [pnpm](https://pnpm.io/).

```bash
pnpm install
pnpm dev        # http://localhost:4321 (search works only after a build)
pnpm build      # astro build + pagefind index into dist/
pnpm preview    # serve the built site
pnpm check      # astro check (types and templates)
```

## Writing a post

Create a Markdown file under `src/content/posts/es/` or `src/content/posts/en/`:

```md
---
title: My post title
description: One or two sentences shown in lists and search results.
date: 2026-10-26
category: homelab        # see src/data/categories.ts
translationKey: my-post  # same value in both languages links the translations
# updated: 2026-11-02
# updateNote: what changed
# draft: true
---

Post content in Markdown.
```

## Deploying to Cloudflare Pages

1. Create the KV namespace for likes and put its id in `wrangler.toml`:
   ```bash
   npx wrangler kv namespace create LIKES
   ```
2. Set a salt used to hash reader identifiers:
   ```bash
   npx wrangler pages secret put LIKES_SALT
   ```
3. Connect the repository in Cloudflare Pages with build command `pnpm build` and output directory `dist`.

Local secrets belong in `.dev.vars`, which is git-ignored.

## Project structure

```text
src/
  components/     UI pieces (masthead, sidebar, message table, post actions…)
  content/posts/  Markdown posts, one folder per language
  data/           categories and the generated masthead star layer
  i18n/           UI strings (es, en)
  layouts/        page shell
  pages/          routes, including the raw .md download endpoint
  scripts/        client-side enhancements
  styles/         global styles and fonts
functions/api/    Cloudflare Pages Function for the like counter
scripts/          banner.mjs, the pixel-art masthead generator
public/           fonts, favicon, masthead image
```

The visual system is documented in [DESIGN.md](DESIGN.md) and the product context in [PRODUCT.md](PRODUCT.md).
